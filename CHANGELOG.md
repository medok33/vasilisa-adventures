# История изменений

## 2026-09-01 — исправление регистра входа

- Логин сайта теперь сравнивается без учёта регистра, поэтому заглавные и
  строчные буквы принимаются одинаково.
- Пароль по-прежнему сравнивается строго с учётом регистра.
- Добавлены автоматические тесты обоих правил.

## 2026-08-29 — автоматическая проверка чтения

- Для всех трёх книг заданы 17 проверяемых вопросов с диапазонами страниц,
  вариантами ответа и однозначными правильными вариантами.
- Вопрос открывается только после дочитывания его диапазона; неверный вариант
  не закрывает вопрос и не даёт звезду.
- Третья звезда за чтение теперь выдаётся только за верный ответ на доступный
  книжный вопрос. Участие мамы в этой проверке не требуется.
- Сервер сам пересчитывает награду за чтение и не принимает присланное
  браузером число звёзд как источник третьей звезды.
- Сохранены ограничения: до 3 звёзд за чтение и до 10 за день.

## 2026-08-29 — адаптивное обучение и закрытый вход (локально)

- Исправлен порог сложности: семь правильных заданий за три дня больше не
  повышают уровень. Теперь обязательны семь последовательных безошибочных дней,
  а после повышения новый семидневный цикл начинается заново.
- Добавлено серверное SQLite-хранилище заданий, попыток, уровней навыков и
  причин адаптации с миграцией прежней истории из `progress.json`.
- Math и English разделены на самостоятельные навыки; ежедневный набор
  содержит текущий уровень, закрепление и небольшой вызов.
- Сохраняются первая и последующие попытки, подсказка и длительность ответа.
- Реализованы защита от точных повторов 30 дней и возврат слабой темы через
  2, 4 и 7 дней без резкого снижения уровня.
- Добавлены форма входа и подписанная HttpOnly-сессия; сайт и API закрыты,
  healthcheck вынесен в публичный `/api/health`.
- Реквизиты входа не добавлены в репозиторий: используются только переменные
  окружения VDS.
- Телефон и ссылки папы удалены из клиентского кода и истории прогресса; после
  входа они выдаются отдельным защищённым API из переменных окружения VDS.
- Docker-образ получает OCI-label с точным commit SHA.
- Добавлены автоматические проверки семи идеальных дней, слабого навыка,
  независимости Math/English, исправления первой ошибки и скользящего окна
  без точных повторов на протяжении 30 дней.
- Пакет ещё не опубликован на production.

## 2026-08-27 — подробная история учебных попыток

- Каждая проверка математики и английского теперь сохраняет отдельную запись
  для каждого вопроса: введённый ответ, верность, номер попытки и время.
- Сохраняются текст задания и ожидаемый ответ, поэтому будущий анализ не зависит
  от повторной генерации старого набора дня.
- Старые дни без подробной истории продолжают загружаться без миграции данных.
- Исправлено начальное число полей английских ответов: шесть полей для шести
  фактических заданий.
- Ошибки по-прежнему не уменьшают награду и могут исправляться без ограничения.
