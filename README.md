# Приключения Василисы

Личное веб-приложение с ежедневными заданиями, дневником, системой наград,
родительской проверкой и PDF-отчётами.

Рабочий сайт: <https://nectarra.ru/>

## Перед началом работы

Каждый новый исполнитель или чат обязан прочитать:

1. `AGENTS.md` — правила работы и ограничения.
2. `docs/PROJECT_STATE.md` — актуальное состояние и незавершённые задачи.
3. `CHANGELOG.md` и `git log --oneline -20` — история изменений.
4. `vds/README.md` — безопасное развёртывание на VDS.

Не начинайте проект заново и не переписывайте существующую архитектуру без
отдельного решения владельца.

## Технологии

- Next.js/Vinext;
- TypeScript;
- Docker Compose для VDS;
- Caddy для `nectarra.ru` и HTTPS;
- отдельное постоянное хранилище прогресса.

## Основные команды

```bash
npm ci
npm run build
```

Развёртывание на VDS выполняется только по инструкции в `vds/README.md`.
