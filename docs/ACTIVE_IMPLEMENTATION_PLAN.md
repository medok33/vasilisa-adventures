# Активный план развития «Приключений Василисы»

Дата создания: 1 сентября 2026 года.

Этот файл — единая рабочая точка передачи проекта между агентами. Любой
исполнитель обязан сначала прочитать `AGENTS.md`, затем этот файл, проверить
фактический `main`, production и данные, и только после этого начинать работу.

## 1. Правила ведения плана

Допустимые статусы:

- `NOT_STARTED` — работа не начиналась;
- `IN_PROGRESS` — один агент ведёт пакет прямо сейчас;
- `BLOCKED` — продолжение невозможно без решения владельца или внешних данных;
- `REVIEW` — код готов, но не прошёл все проверки или не опубликован;
- `DONE` — выполнены критерии приёмки, проверки, commit и production-проверка;
- `DEFERRED` — владелец осознанно отложил пакет.

Одновременно статус `IN_PROGRESS` может иметь только один крупный пакет.
Перед началом агент указывает дату, своё обозначение и базовый commit. После
завершения он обязан в том же файле:

1. сменить статус;
2. перечислить фактические изменения;
3. записать commit SHA;
4. перечислить выполненные тесты и их результат;
5. указать, опубликована ли правка на production;
6. зафиксировать известные риски и следующий конкретный шаг;
7. добавить строку в журнал выполнения в конце файла.

Запрещено ставить `DONE`, если отсутствует хотя бы один критерий приёмки.
Запрещено записывать сюда логины, пароли, ключи, cookies, токены, персональные
данные ребёнка, содержимое БД и серверного `.env`.
