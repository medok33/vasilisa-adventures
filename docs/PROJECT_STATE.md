# Текущее состояние проекта

Дата фиксации: 1 сентября 2026 года.

## Текущий пакет R1

- Сценарий чтения разделён на сохранение страниц, необязательный смысловой
  вопрос по текущему диапазону и однократное финальное поздравление.
- В дневном прогрессе появилась связанная запись `readingSession`: дата, книга,
  диапазон, время, вопросы, ответы и состояние завершения.
- Третья звезда вычисляется сервером только по правильным ответам текущего дня;
  унаследованные ответы прошлых дней на награду не влияют.
- Карта чтения содержит 17 важных смысловых контрольных точек по трём книгам.
  При любом диапазоне появляется не больше одного вопроса; между контрольными
  точками вопроса нет.
- После последней страницы книга предлагает персональную книжную заметку
  Василисы. Текст сохраняется без оценки, а за завершённую книгу и заметку один
  раз начисляется отдельный папин бонус `10 ⭐` вне дневного лимита.
- Детская обратная связь переписана в поддерживающем тоне, красное состояние
  повторной попытки заменено на спокойное нейтральное оформление.
- Локально пройдены 26 автоматических тестов, Vinext production build, lint без
  ошибок и VDS Next.js build с TypeScript-проверкой.
- Production пока не обновлён; до публикации пакет остаётся `REVIEW`.

## Реализовано

- семь ежедневных миссий;
- уникальный набор математики, английского, порядка, добрых дел и самостоятельности на каждую московскую дату;
- сохранение числа попыток по математике и английскому без штрафов;
- подробная история каждой проверки по каждому учебному вопросу: первый и
  последующие ответы, верность, номер попытки и время проверки;
- секретная миссия дня и собственный вариант ответа;
- недельная цель из пяти солнечных фрагментов;
- последовательная библиотека из трёх проверенных изданий с ISBN, диапазонами страниц и счётчиком завершённых книг;
- накопительный учёт прочитанных диапазонов с автоматическим переносом прежних полей страниц;
- вопросы только по уже прочитанной части книги;
- 17 автоматических вопросов по трём книгам с привязкой к диапазонам страниц
  и вариантами ответа;
- третья звезда чтения только за верный вариант ответа; её пересчитывает
  сервер, без участия мамы;
- изменение оформления иконок выполненных миссий;
- адаптивная главная страница и анимированное настроение Василисы;
- стабильная навигация между разделами;
- дневник «Мой день» с историей по датам;
- отдельные поля «Получилось», «Не получилось» и «Просьбы папе»;
- звонок папе и переходы в VK/MAX;
- распределение награды между лимитом и копилкой с шагом 10 рублей;
- родительская проверка дня;
- подпись мамы пальцем;
- яркий игровой PDF-отчёт после закрытия дня с датой и подписью мамы справа внизу;
- сохранение прогресса в отдельном постоянном хранилище.

## Готово локально, ещё не опубликовано на VDS

- серверная авторизация всего сайта и API по логину и паролю;
- HttpOnly-сессия с HMAC-подписью и сроком семь дней;
- закрытый API прогресса; публичным остаётся только `/api/health`;
- закрытый API контактов папы; телефон и ссылки отсутствуют в текущем дереве
  GitHub и не записываются в прогресс ребёнка. Прежняя публичная Git-история
  могла сохранить старые значения и требует отдельного согласованного аудита;
- SQLite `/data/learning.sqlite` с таблицами `learning_items`,
  `daily_assignments`, `attempts`, `skill_progress`, `adaptation_log` и
  `learning_days`;
- однократная миграция прежней учебной истории из `progress.json`;
- отдельные навыки Math и English, подсказки, длительность и серверная запись
  каждой попытки;
- ежедневная схема 3/1/1 для Math и 4/1/1 для English;
- защита точных заданий от повтора 30 дней и закрепление через 2/4/7 дней;
- повышение только конкретного навыка после семи последовательных календарных
  дней без ошибок и подсказок; по навыку дополнительно нужны минимум семь
  первых попыток за три дня, а после повышения начинается новый цикл;
- OCI-label `org.opencontainers.image.revision` для проверки коммита образа.

Проверено локально: 21 тест, обычная Vinext-сборка и VDS production-сборка.
Интеграционный запуск подтвердил `307` на форму входа, `401` для API без
сессии, `200` для health, главной и learning API после входа. Production
`nectarra.ru` в этом пакете пока не изменялся.

## Не завершено

- Автоматическая доставка сообщений папе во VK/MAX не подключена. Личная
  страница VK не даёт приложению права отправлять уведомления. Нужен отдельный
  официальный бот/сообщество и его безопасные серверные настройки.
- Страницы и формулировки 17 смысловых контрольных точек нужно окончательно
  сверить с фактическими изданиями книг; намеренно не планируется покадровый
  опрос по каждой главе.
- Учебный пакет и авторизация ожидают разрешения владельца на публикацию VDS.
- Точное соответствие English школьному учебнику требует названия и издания
  учебника; текущая стартовая карта соответствует базовому уровню 3 класса.

## Инфраструктурные ограничения

- На VDS также работает Weight App. Его нельзя перезапускать или изменять.
- Обновление сайта выполняется пересборкой только сервиса `app`; Weight App не затрагивается.
- Том прогресса нельзя удалять или пересоздавать.
- Docker label production показывает рабочий каталог
  `/opt/vasilisa-adventures/source/vds`, но серверный каталог не содержит
  `.git`, а текущий образ не содержит revision-label. Поэтому прежний SHA
  production невозможно доказать. Следующий образ должен собираться с
  `APP_REVISION=$(git rev-parse HEAD)`.
