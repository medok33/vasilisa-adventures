## Реализовано

- семь ежедневных миссий;
- уникальный набор математики, английского, порядка, добрых дел и самостоятельности на каждую московскую дату;
- сохранение числа попыток по математике и английскому без штрафов;
- подробная история каждой проверки по каждому учебному вопросу: первый и
  последующие ответы, верность, номер попытки и время проверки;
- секретная миссия дня и собственный вариант ответа;
- недельная цель из пяти солнечных фрагментов;
- последовательная библиотека из трёх проверенных изданий с ISBN, диапазонами страниц и счётчиком завершённых книг;
- накопительный учёт прочитанных диапазонов с автоматическим переносом прежних полей страниц;
- вопросы только по уже прочитанной части книги;
- изменение оформления иконок выполненных миссий;
- адаптивная главная страница и анимированное настроение Василисы;
- стабильная навигация между разделами;
- дневник «Мой день» с историей по датам;
- отдельные поля «Получилось», «Не получилось» и «Просьбы папе»;
- звонок папе и переходы в VK/MAX;
- распределение награды между лимитом и копилкой с шагом 10 рублей;
- родительская проверка дня;
- подпись мамы пальцем;
- яркий игровой PDF-отчёт после закрытия дня с датой и подписью мамы справа внизу;
- сохранение прогресса в отдельном постоянном хранилище.

## Не завершено

- Автоматическая доставка сообщений папе во VK/MAX не подключена. Личная
  страница VK не даёт приложению права отправлять уведомления. Нужен отдельный
  официальный бот/сообщество и его безопасные серверные настройки.
- Полный набор вопросов по каждой главе можно расширять по мере прохождения книг; текущая версия содержит безопасные контрольные точки без спойлеров.
- Дополнительная звезда за ответ на книжный вопрос и осторожная адаптация
  сложности ещё не реализованы. Темы, уровни, подсказки и длительность ответа
  будут добавлены следующим учебным пакетом. Проектное решение зафиксировано в
  `docs/AI_LEARNING_ARCHITECTURE.md`.

## Инфраструктурные ограничения

- На VDS также работает Weight App. Его нельзя перезапускать или изменять.
- Обновление сайта выполняется пересборкой только сервиса `app`; Weight App не затрагивается.
- Том прогресса нельзя удалять или пересоздавать.
- Серверная ветка `deploy/vasilisa-20260827` отслеживает код из GitHub. Перед
  каждым обновлением всё равно нужно сверять фактические ветку, `HEAD` и
  чистоту рабочего дерева; слепой `pull` запрещён.
